What 40% more load does when generators run out of reactive power

I scaled every load in the IEEE 14-bus case to 140% and solved it two times. In the first solve, the generators make all the reactive power they need to hold their voltage setpoints. In the second solve, each generator stays inside its real Qmin to Qmax range. pandapower, an independent open source solver, solved the same case file as a check.

Limits. This is a balanced steady state model. It has no dynamics, faults or protection. The public case has no line ratings, so the ratings here are illustrative: 1.5× the base case flow, at least 50 MVA. The solver enforces reactive limits at every generator except the slack bus, which must balance the system. The page shows the slack Q against its limits but never fixes it. Use this to learn, not to plan a network.
